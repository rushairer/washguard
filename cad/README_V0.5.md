# WashGuard ADXL355 底座 V0.5

## 核心修复

V0.4 四个 PCB 支撑柱根部通过通用圆边 fillet 生成，在 CAD 视图里会呈现明显的环状/甜甜圈外观。

V0.5 改为：

- 四个 PCB 支撑柱分别独立建模；
- 柱身直径仍为 5.5 mm；
- 根部在约 0.8 mm 范围内平滑展开到底板；
- 过渡高度约 0.9 mm；
- 通过连续旋转曲面形成扩根；
- 不再对支撑柱底部圆边调用通用 fillet；
- 目标是与压线柱类似的“柱身自然过渡到底板”效果，而不是独立圆环。

## 保留

- 压线区域 R0.8 根部过渡；
- 压线片无 0.01 mm 残余薄片；
- 压线片边缘倒角；
- 梯形线槽；
- 底座 44 × 32 × 2.4 mm。
