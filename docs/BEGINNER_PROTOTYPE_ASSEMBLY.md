# WashGuard 第一版原型机：小白组装指南

> 目标：即使没有电子制作经验，也能把 **XIAO ESP32S3 + EVAL-ADXL355Z** 安全地组装成可以采集洗衣机振动的第一版工程原型。

## 1. 第一版应该长什么样

第一版不要把两块板都硬塞在同一块普通面包板上。

推荐结构：

~~~text
Mac / PC
   |
   | USB-C 数据线（同时供电 + 串口数据）
   v
+------------------------------+
| 400 孔半尺寸面包板           |
|                              |
|      XIAO ESP32S3            |
|      跨在中央沟槽上          |
|                              |
| 红色电源轨：3.3V             |
| 蓝色电源轨：GND              |
+-----------+------------------+
            | 8 根短杜邦线
            v
      EVAL-ADXL355Z
      （不插普通面包板）
            |
            v
       洗衣机机身
~~~

这样做有两个原因：

1. EVAL-ADXL355Z 的 P1/P2 是两个 2×3、2.54 mm 双排接口，普通面包板很容易把相邻针脚放进同一个导电排，从而短接。
2. 真正采振动时，ADXL355 应尽量刚性跟随洗衣机机身；如果把它插在松软的面包板上，面包板本身可能改变振动信号。

因此：

- 面包板负责固定 XIAO 和分配电源；
- ADXL355 单独固定到洗衣机；
- 两者使用短杜邦线连接。

## 2. 第一版需要准备什么

### 必须品

- 1 × Seeed Studio XIAO ESP32S3
- 1 × EVAL-ADXL355Z
- 1 × 400 孔半尺寸无焊面包板，建议带红/蓝电源轨
- 2 × 1×7、2.54 mm 直插公排针，给 XIAO 使用
- 2 × 2×3、2.54 mm 直插公排针，给 EVAL-ADXL355Z 使用
- 至少 8 根母对公杜邦线，建议 10～15 cm
- 1 × USB-C 数据线，不要使用只能充电的线
- 烙铁、焊锡、助焊剂
- 万用表

### 推荐品

- 放大镜
- 镊子
- 帮手夹 / 第三只手
- Kapton 绝缘胶带或其他薄绝缘胶带
- 薄型双面胶
- 标签纸或彩色胶带

## 3. 为什么两块板都需要焊排针

### XIAO ESP32S3

XIAO ESP32S3 默认通常没有焊接排针。为了插进面包板，需要给两侧各焊一排 1×7 公排针。

要求：

- 长针朝下，以后插面包板；
- 短针穿过 XIAO PCB；
- 在 XIAO PCB 一侧焊接。

### EVAL-ADXL355Z

EVAL-ADXL355Z 的官方设计在 P1 和 P2 位置预留了两个 2×3、2.54 mm 双排接口孔，官方 BOM 中的公排针为未装配状态。

如果你手里的板子只有孔、没有针，就各焊一个 2×3 公排针。

建议：

- 长针朝上；
- 短针穿过 PCB；
- 从 PCB 背面焊接。

这样后面可以直接把母头杜邦线插在长针上，而且板子底部不会伸出很长的排针。

如果收到的 EVAL-ADXL355Z 已经焊好排针，不要重复焊。

## 4. 焊 XIAO：新手最简单的方法

### 第一步：完全断电

焊接时：

- 不接 USB；
- 不接 ADXL355；
- 不接任何外部电源。

### 第二步：用面包板帮排针定位

1. 把两根 1×7 公排针的长针分别插进面包板；
2. 两排保持平行；
3. 把 XIAO 套到上面的短针上；
4. 让 USB-C 接口朝面包板外侧，方便以后插线；
5. 确认 XIAO 没有歪。

面包板此时只是焊接定位夹具。

### 第三步：先焊四个角

先只焊：

- 左排最上面一个；
- 左排最下面一个；
- 右排最上面一个；
- 右排最下面一个。

然后检查板子是否水平、排针是否垂直。

### 第四步：焊剩余针脚

逐个焊完，最后检查：

- 焊点覆盖焊盘和针脚；
- 没有连到旁边焊点；
- 没有大块焊锡形成焊桥。

## 5. 焊 EVAL-ADXL355Z

P1、P2 各焊一个 2×3 公排针。

推荐方向：

~~~text
        长针
        ↑ ↑
      +------+
      |排针座|
------+------ +------  EVAL-ADXL355Z PCB
        ↓ ↓
      短焊脚
~~~

目标是长针在板子正面朝上，后续方便插母头杜邦线。

建议：

1. 用第三只手或耐热胶带固定排针；
2. 先焊一个角；
3. 检查排针是否垂直；
4. 再焊对角；
5. 最后补齐其余焊点；
6. 检查是否有焊桥。

不要在 ADXL355 芯片附近长时间加热。

## 6. 面包板怎么放 XIAO

推荐 400 孔半尺寸面包板。

普通面包板中央有一条沟：

~~~text
a b c d e   |   f g h i j
            ↑
          中央沟槽
~~~

XIAO 的两排针要跨过中央沟槽，让左右两侧针脚进入互不相连的区域。

USB-C 接口尽量朝面包板外面，避免 USB 线压在面包板上。

## 7. 先认识面包板的内部连接

面包板不是每个孔都独立。

典型结构：

~~~text
同一编号：

a - b - c - d - e    这 5 个孔内部相连

f - g - h - i - j    这 5 个孔内部相连

e 和 f 中间隔着沟，不相连。
~~~

两边长电源轨通常类似：

~~~text
+ + + + + + + + +    红色：我们只放 3.3V
- - - - - - - - -    蓝色：GND
~~~

有些面包板的长电源轨中间是断开的。第一次使用前最好用万用表通断档确认。

## 8. 第一版电源从哪里来

第一版不需要电池，也不需要额外电源模块。

~~~text
电脑 USB
   | 5V
   v
XIAO ESP32S3
   | 板载稳压器
   v
  3.3V
   |
   v
EVAL-ADXL355Z
~~~

USB-C 同时完成：

1. 给 XIAO 供电；
2. XIAO 板载稳压器产生 3.3V；
3. XIAO 的 3V3 给 ADXL355 的 VDD 与 VDDIO 供电；
4. USB 同时把振动数据传回电脑。

绝对不要把 XIAO 的 5V/VBUS 接到 EVAL-ADXL355Z 的 VDD 或 VDDIO。

第一版 ADXL355 只使用 3.3V。

## 9. 先接面包板的 3.3V 和 GND

定义：

- 红色电源轨 = 3.3V
- 蓝色电源轨 = GND

连接：

~~~text
XIAO 3V3 ---- 红色 + 电源轨
XIAO GND ---- 蓝色 - 电源轨
~~~

不要把 XIAO 的 5V 接入任何电源轨。

## 10. EVAL-ADXL355Z 的 P1/P2 怎么认

P1、P2 都是 2×3。

### P1

~~~text
P1
+-------------+
| 1       2   |
| 3       4   |
| 5       6   |
+-------------+

1 = VDD
2 = INT1       第一版不用
3 = VDDIO
4 = INT2       第一版不用
5 = GND
6 = DRDY
~~~

### P2

~~~text
P2
+-------------+
| 1       2   |
| 3       4   |
| 5       6   |
+-------------+

1 = V1P8ANA    第一版不接
2 = CS
3 = V1P8DIG    第一版不接
4 = SCLK
5 = MISO
6 = MOSI
~~~

不要凭左上角、右上角猜实物方向。

拿实物时：

1. 找 PCB 丝印中的 P1/P2；
2. 对照官方图；
3. 找 Pin 1 标记或方形焊盘；
4. 再确定 1～6。

如果还有任何不确定，第一次上电前应拍清晰正反面照片逐孔确认。

## 11. 八根线怎么接

| 颜色建议 | EVAL-ADXL355Z | XIAO / 面包板 | 用途 |
| --- | --- | --- | --- |
| 红 | P1-1 VDD | 红色 3.3V 电源轨 | 传感器主电源 |
| 红 | P1-3 VDDIO | 红色 3.3V 电源轨 | 数字接口电源 |
| 黑 | P1-5 GND | 蓝色 GND 电源轨 | 共地 |
| 白 | P1-6 DRDY | XIAO D2 / GPIO3 | 数据就绪 |
| 橙 | P2-2 CS | XIAO D3 / GPIO4 | SPI 片选 |
| 黄 | P2-4 SCLK | XIAO D8 / GPIO7 | SPI 时钟 |
| 蓝 | P2-5 MISO | XIAO D9 / GPIO8 | ADXL → XIAO |
| 绿 | P2-6 MOSI | XIAO D10 / GPIO9 | XIAO → ADXL |

颜色只是建议，真正判断以两端针脚名称为准。

第一版保持不接：

- P1-2 INT1
- P1-4 INT2
- P2-1 V1P8ANA
- P2-3 V1P8DIG

## 12. 杜邦线怎么插

EVAL 上是公排针，所以 EVAL 这一端用杜邦线母头。

另一端是公头，插面包板。

例如 DRDY：

~~~text
EVAL P1-6
    |
    | 母头
[母------公]
          |
          v
面包板中与 XIAO D2 同一导电排的空孔
~~~

电源：

~~~text
EVAL P1-1 VDD   ---- 红色 3.3V 轨
EVAL P1-3 VDDIO ---- 红色 3.3V 轨
EVAL P1-5 GND   ---- 蓝色 GND 轨
~~~

## 13. 推荐的桌面排布

~~~text
             USB-C
               |
               v
+-----------------------------+
| 面包板                      |
|                             |
|  + 3V3 ----------------+    |
|  - GND ------------+   |    |
|                    |   |    |
|      +-----------+ |   |    |
|      |   XIAO    | |   |    |
|      | ESP32S3   | |   |    |
|      +-----------+ |   |    |
+----------+---------+---+----+
           | D2 D3 D8 D9 D10
           |
           | 8 根短杜邦线
           v
      +-------------+
      |EVAL-ADXL355Z|
      +-------------+
~~~

信号线尽量：

- 短；
- 不绕圈；
- 不和 USB 线缠在一起；
- 不在洗衣机上自由甩动。

第一版推荐 10～15 cm 左右。

## 14. 第一次不要直接开始洗衣

### 阶段 A：只测试 XIAO

1. EVAL 完全不接；
2. XIAO 插在面包板；
3. USB-C 接电脑；
4. 确认电脑能识别 XIAO；
5. 确认 XIAO 不异常发热。

然后拔掉 USB。

### 阶段 B：断电状态下接 EVAL

把八根线全部接好。

### 阶段 C：用万用表检查

至少检查：

1. 3V3 和 GND 之间没有明显短路；
2. XIAO 3V3 连到 EVAL P1-1；
3. XIAO 3V3 连到 EVAL P1-3；
4. XIAO GND 连到 EVAL P1-5；
5. D2、D3、D8、D9、D10 分别接到正确位置。

### 阶段 D：第一次联合上电

1. 确认没有裸线互相接触；
2. USB 插电脑；
3. 观察几秒；
4. 如果明显发热、异味或冒烟，立即拔线；
5. 正常则进入固件烧录和串口测试。

## 15. 第一次串口成功应该看到什么

烧录 WashGuard 采集固件后，启动日志应该出现类似：

~~~text
# washguard_acquisition,version=...
# adxl355_ids,AD,1D,ED
# config,odr_hz=500,range_g=2,...
# ready
~~~

其中 AD,1D,ED 是重要的第一关。

它说明 XIAO 已经通过 SPI 正确读到 ADXL355 身份寄存器。

如果不是这三个值，不开始洗衣实验，先检查接线。

## 16. 放到洗衣机上时，不要让裸 PCB 接触金属

洗衣机表面通常是金属。

不要让 EVAL-ADXL355Z PCB 背面的焊点直接碰金属外壳。

第一版可以采用：

~~~text
EVAL-ADXL355Z
      |
薄绝缘层（Kapton / 薄塑料片）
      |
薄型固定胶 / 边缘胶带
      |
洗衣机金属外壳
~~~

要求：

- 绝缘；
- 尽量薄；
- 尽量硬；
- 不使用很厚、很软的海绵双面胶。

长期版以后再设计磁吸外壳。

## 17. 面包板/XIAO 放哪里

实际实验时：

- ADXL355 固定在洗衣机上；
- 面包板 + XIAO 放在旁边稳定位置；
- 不让面包板自由晃动；
- 不让面包板撞洗衣机；
- 杜邦线留一点松量，但不能甩动；
- USB 线固定一下，避免线缆拖拽传感器。

机械关系：

~~~text
洗衣机机身
   |
   +-- ADXL355  ← 必须牢固跟随机身

附近稳定位置
   |
   +-- 面包板 + XIAO
            |
            +-- USB → 电脑
~~~

## 18. 第一版为什么不用电池

USB 是当前最简单可靠的方案：

- 不需要充电模块；
- 不需要研究电池保护；
- 电压稳定；
- 同时可以传数据；
- 出问题容易排查。

WG-EXP-001 阶段坚持：

**电脑 USB-C → XIAO → 3.3V → ADXL355**

数据路线：

**ADXL355 → SPI → XIAO → USB → 电脑 CSV**

## 19. 新手最容易犯的 10 个错误

1. 把 5V 接到 ADXL355。
2. 把 GND 接错。
3. 把 P1/P2 的方向看反。
4. 把 MISO 和 MOSI 接反。
5. XIAO 两排针没有跨面包板中央沟槽。
6. 面包板电源轨中间断开却以为整条相通。
7. EVAL 2×3 排针直接插普通面包板造成短接。
8. 焊锡把两个相邻焊盘连起来。
9. 用只能充电的 USB-C 线，电脑找不到串口。
10. 裸 EVAL PCB 直接接触洗衣机金属外壳。
