### 2. 第一阶段技术目标确定

第一阶段不急于做 UI、App、云服务、定制 PCB 或机器学习。

当前唯一需要先证明的问题是：

> 将 ADXL355 固定在洗衣机外壳后，真实振动数据是否足以稳定观察和区分有价值的运行状态？

因此，第一阶段以真实数据为中心。

### 3. 数据采集方案确定

第一版原型计划使用：

- EVAL-ADXL355Z；
- XIAO ESP32S3；
- SPI；
- USB-C 供电；
- USB 串口传输到电脑。

初始采集参数：

- 三轴 XYZ；
- 500 Hz ODR；
- ±2 g 量程；
- DRDY 驱动采样；
- 保存 20 bit 原始值；
- 保存单调时间戳与样本序号；
- 主机端保存 CSV；
- 同步人工记录 Ground Truth。

实验顺序确定为：

1. `WG-PREFLIGHT-001`：约 60 秒静止数据 + 轻敲机身，检查通信、采样率、丢样、削顶等；
2. `WG-EXP-001`：第一台洗衣机一个完整洗衣周期；
3. 后续依次验证不同安装位置、不同负载、不同洗衣程序和不同洗衣机。

### 4. 泛化路线确定

不直接把某一台洗衣机的固定流程作为最终算法。

当前算法方向：

~~~text
ADXL355 原始 XYZ
        ↓
DSP / 去重力 / 滤波 / 方向归一化
        ↓
Machine Profile 自校准
        ↓
统计与频域特征
        ↓
Motion Primitive
        ↓
时序 / 状态模型
        ↓
Idle / Running / Finished
洗涤 / 脱水 / 异常等用户状态
~~~

机器学习不是第一阶段前提。未来有足够跨机型数据后，再评估传统 ML 或轻量时序模型是否真正带来价值。

### 5. 原型机械结构设计

决定使用 EVAL-ADXL355Z 四个安装孔，将传感器板固定在 3D 打印刚性绝缘底座上。

原型结构原则：

- 四点螺丝固定；
- 底座绝缘、刚性；
- 不使用软泡棉作为传感器与洗衣机之间的隔层；
- 排针在原型阶段朝上；
- 使用短杜邦线；
- 设计线缆应力释放结构，避免线束拉扯传感器板；
- 底座通过薄双面胶固定到洗衣机。

CAD 已经历多轮结构修订，重点处理：

- PCB 安装柱；
- 支撑柱根部应力过渡；
- 压线托座；
- 压线片；
- FDM 无支撑打印；
- 线槽与倒角；
- STEP / STL 几何一致性。

当前 CAD 属于**设计草模，尚未实际 3D 打印和装配验证**。

### 6. 产品化方向初步确定

当前决定：未来产品可以继续使用 **EVAL-ADXL355Z 作为正式 Sensor PCB**，暂不强制重画 ADXL355 LGA 传感器板。

产品大体采用：

~~~text
单一外壳
├── Sensor Zone
│   └── EVAL-ADXL355Z
│       四点刚性固定到底壳
│
└── Main Zone
    └── WashGuard Main PCB
        ├── ESP32-S3
        ├── USB-C
        ├── 电源
        ├── 蜂鸣器
        └── 按键
~~~

Sensor PCB 与 Main PCB 优先侧向并排，不把主控板直接叠压在 ADXL355 上。

正式产品不继续使用松动风险较高的杜邦线，后续考虑短焊接线束、低矮锁扣连接器或小型接口转接板。

当前产品设想中**没有 RGB 状态灯**，提示方式以蜂鸣器和软件端状态为主。
