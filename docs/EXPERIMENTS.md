# WashGuard 实验计划与记录规范

## 1. 实验原则

WashGuard 的算法结论必须来自可复现实验。

每次实验至少记录：

- 实验编号；
- 日期；
- 洗衣机品牌/型号（已知时）；
- 程序名称；
- 衣物负载情况；
- 传感器安装位置；
- 传感器方向；
- 采样率与量程；
- 固件版本/提交号；
- 原始数据文件；
- Ground Truth 标注；
- 异常情况；
- 初步观察；
- 结论与下一步。

## 2. 数据格式

首版建议最少保留：

```csv
timestamp_us,x_raw,y_raw,z_raw,x_g,y_g,z_g
```

要求：

- 时间戳单调递增；
- 原始 ADC/寄存器值尽量保留；
- 换算后的 g 值同时保留；
- 不用 RMS、FFT 等派生结果替换源数据；
- 派生特征应可以从原始数据重新计算。

Ground Truth 建议单独保存：

```csv
timestamp,observer_state,note
2026-09-27T10:00:00,start,按下启动键
2026-09-27T10:03:12,wash,观察到明显低速往复
2026-09-27T10:31:40,spin,进入高速脱水
2026-09-27T10:39:08,done,机器提示完成
```

## 3. WG-EXP-001：首次完整周期采集

### 目标

验证外部 ADXL355 是否能够连续、稳定地记录一个完整洗衣周期，并让人工从时域/频域图中观察到明显状态差异。

### 原型

- EVAL-ADXL355Z
- XIAO ESP32S3
- SPI
- USB 供电
- USB 串口或可靠的本地数据输出

### 初始参数

- 采样率：500 Hz
- 量程：±2 g
- 三轴全部采集
- 若出现明显削顶，改为更大量程并重新记录

这些参数是实验起点，不是最终产品规格。

### 安装

第一次实验优先固定在洗衣机机身较刚性的部位，例如顶部靠后区域。

要求：

- 固定牢靠；
- 整个周期内不能移动；
- 记录传感器朝向；
- 拍照记录安装位置，便于复现实验。

### 执行步骤

1. 上电后静置采样 1～2 分钟，记录环境与静止基线。
2. 启动洗衣程序。
3. 连续记录完整周期，不中断采样。
4. 人工记录可观察到的关键状态变化时间。
5. 洗衣完成后继续记录 2～5 分钟静止数据。
6. 保存原始数据、标注文件、实验说明和安装照片。
7. 绘制 X/Y/Z、三轴合成动态量、滑动 RMS、峰峰值和频谱/时频图。
8. 记录是否存在丢样、时间戳跳变、削顶、串口阻塞或复位。

### 验收标准

WG-EXP-001 完成至少需要满足：

- 完整周期无明显采集链路中断；
- 时间戳连续可分析；
- 三轴数据没有大面积削顶；
- 有人工 Ground Truth；
- 可以从至少一种派生特征上观察到不同运行阶段的明显变化；
- 数据和实验元信息足够让下一次实验复现。

## 4. WG-EXP-002：不同安装位置

在同一台洗衣机上比较：

- 顶部靠后；
- 左侧；
- 右侧；
- 其他结构较刚性且便于安装的位置。

目标不是寻找“振动最大”的位置，而是寻找：

- 信噪比较好；
- 状态差异明显；
- 稳定；
- 方便用户安装；
- 对日常使用影响小

的综合位置。

同时研究哪些特征对安装位置最不敏感。

## 5. WG-EXP-003：不同负载

在相同机型、相同安装位置、相同程序下比较：

- 空桶或极低负载；
- 小负载；
- 正常负载；
- 较高负载。

目标：确定绝对振幅受负载变化的程度，以及归一化是否能降低这种差异。

## 6. WG-EXP-004：不同洗衣程序

同一台机器至少比较：

- 标准程序；
- 快洗程序；
- 另一个明显不同的程序。

目标：验证底层 Motion Primitive 是否比“固定程序阶段”更稳定。

## 7. WG-EXP-005：跨洗衣机验证

当第一台机器的信号分析基本稳定后，引入第二台不同机型或不同结构的洗衣机。

目标：

- 检验已有特征的跨机型泛化；
- 验证 Machine Profile 自校准是否必要；
- 明确哪些规则可以全局共享，哪些必须每台机器自适应。

## 8. 后续异常实验

基础状态稳定后再安排：

- 偏载；
- 明显撞桶；
- 异常强振动；
- 中途暂停；
- 断电/重新启动；
- 运行中人为移动传感器。

异常实验不阻塞 WG-EXP-001。
