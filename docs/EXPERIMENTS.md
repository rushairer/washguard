# WashGuard 实验计划与记录规范

## 1. 实验原则

WashGuard 的算法结论必须来自可复现实验。

每次实验至少记录：

- 实验编号；
- 日期；
- 洗衣机品牌/型号（已知时）；
- 程序名称；
- 衣物负载情况；
- 传感器安装位置；
- 传感器方向；
- 采样率与量程；
- 固件版本/提交号；
- 原始数据文件；
- Ground Truth 标注；
- 异常情况；
- 初步观察；
- 结论与下一步。

## 2. 数据格式

首版采集 CSV 保留：

```csv
timestamp_us,seq,x_raw,y_raw,z_raw,x_g,y_g,z_g
```

要求：

- `timestamp_us` 使用 ESP32-S3 单调时间；
- `seq` 必须连续，用于检测丢样；
- 原始 20 bit XYZ 数据必须保留；
- 换算后的 g 值同时保留；
- 不用 RMS、FFT 等派生结果替换源数据；
- 派生特征必须可以从原始数据重新计算。

采集工具还必须在 `.meta.json` 中记录：

- 第一帧设备 `timestamp_us`；
- 第一帧被主机接收时的 UTC 时间；
- 样本总数；
- 首尾 seq；
- seq 缺口数；
- 机器、程序、负载、安装位置、方向等元信息。

这样人工 Ground Truth 的墙上时间可以与设备单调时间建立锚点关系。

Ground Truth 建议单独保存：

```csv
timestamp_local,elapsed_s,state,note
2026-09-27T10:00:00+08:00,0,start,按下启动键
2026-09-27T10:03:12+08:00,192,wash,观察到明显低速往复
2026-09-27T10:31:40+08:00,1900,spin,进入高速脱水
2026-09-27T10:39:08+08:00,2348,done,机器提示完成
```

## 3. WG-PREFLIGHT-001：正式洗衣前采集链路预检

在浪费一个完整洗衣周期之前，先做一个短预检。

### 目标

确认：

- ADXL355 通信正确；
- 500 Hz 连续采样成立；
- DRDY 驱动链路工作；
- USB 串口吞吐量足够；
- 没有明显丢样；
- 没有静止状态削顶；
- 手动轻敲机身时三轴确实有响应。

### 步骤

1. 按 `docs/HARDWARE_PROTOTYPE.md` 完成接线。
2. 烧录 `firmware/acquisition`。
3. 传感器固定后保持静止，采集至少 60 秒。
4. 中间轻敲洗衣机机身 3～5 次，力度不需要大。
5. 结束采集。
6. 使用 `tools/validate_capture.py` 检查结果。

示例：

```bash
python3 tools/capture_serial.py \
  --port /dev/cu.usbmodem101 \
  --output data/raw/WG-PREFLIGHT-001/run-001.csv \
  --experiment WG-PREFLIGHT-001 \
  --mount "顶部靠后"
```

然后：

```bash
python3 tools/validate_capture.py \
  data/raw/WG-PREFLIGHT-001/run-001.csv
```

### 通过标准

至少满足：

- 估算采样率处于 480～520 Hz；
- `seq` 无缺口；
- 时间戳严格单调；
- 无削顶；
- 设备日志中的 `missed_drdy=0`；
- 设备日志中的 `queue_drop=0`；
- 轻敲事件在原始数据里明显可见。

预检不通过时，先修采集链路，不进入 WG-EXP-001。

## 4. WG-EXP-001：首次完整周期采集

### 目标

验证外部 ADXL355 是否能够连续、稳定地记录一个完整洗衣周期，并让人工从时域/频域图中观察到明显状态差异。

### 原型

- EVAL-ADXL355Z
- XIAO ESP32S3
- SPI
- USB 供电
- USB 串口数据输出

### 初始参数

- 采样率：500 Hz
- LPF：125 Hz
- HPF：关闭
- 量程：±2 g
- 三轴全部采集
- 若出现明显削顶，改为更大量程并重新记录

这些参数是实验起点，不是最终产品规格。

### 安装

第一次实验优先固定在洗衣机机身较刚性的部位，例如顶部靠后区域。

要求：

- 固定牢靠；
- 整个周期内不能移动；
- 记录传感器朝向；
- 拍照记录安装位置，便于复现实验；
- 固定 USB 线与连接线，避免线缆摆动污染振动信号。

### 执行步骤

1. 先完成 WG-PREFLIGHT-001。
2. 上电后静置采样 1～2 分钟，记录环境与静止基线。
3. 启动洗衣程序。
4. 连续记录完整周期，不中断采样。
5. 人工记录可观察到的关键状态变化时间。
6. 洗衣完成后继续记录 2～5 分钟静止数据。
7. 保存原始数据、标注文件、实验说明和安装照片。
8. 运行采集质量检查工具。
9. 质量通过后再绘制 X/Y/Z、三轴合成动态量、滑动 RMS、峰峰值和频谱/时频图。
10. 记录是否存在丢样、时间戳跳变、削顶、串口阻塞或复位。

### 验收标准

WG-EXP-001 完成至少需要满足：

- 完整周期无明显采集链路中断；
- 时间戳连续可分析；
- `seq` 无不可解释缺口；
- 三轴数据没有大面积削顶；
- 有人工 Ground Truth；
- Ground Truth 与设备时间存在可追溯时间锚点；
- 可以从至少一种派生特征上观察到不同运行阶段的明显变化；
- 数据和实验元信息足够让下一次实验复现。

## 5. WG-EXP-002：不同安装位置

在同一台洗衣机上比较：

- 顶部靠后；
- 左侧；
- 右侧；
- 其他结构较刚性且便于安装的位置。

目标不是寻找“振动最大”的位置，而是寻找：

- 信噪比较好；
- 状态差异明显；
- 稳定；
- 方便用户安装；
- 对日常使用影响小

的综合位置。

同时研究哪些特征对安装位置最不敏感。

## 6. WG-EXP-003：不同负载

在相同机型、相同安装位置、相同程序下比较：

- 空桶或极低负载；
- 小负载；
- 正常负载；
- 较高负载。

目标：确定绝对振幅受负载变化的程度，以及归一化是否能降低这种差异。

## 7. WG-EXP-004：不同洗衣程序

同一台机器至少比较：

- 标准程序；
- 快洗程序；
- 另一个明显不同的程序。

目标：验证底层 Motion Primitive 是否比“固定程序阶段”更稳定。

## 8. WG-EXP-005：跨洗衣机验证

当第一台机器的信号分析基本稳定后，引入第二台不同机型或不同结构的洗衣机。

目标：

- 检验已有特征的跨机型泛化；
- 验证 Machine Profile 自校准是否必要；
- 明确哪些规则可以全局共享，哪些必须每台机器自适应。

## 9. 后续异常实验

基础状态稳定后再安排：

- 偏载；
- 明显撞桶；
- 异常强振动；
- 中途暂停；
- 断电/重新启动；
- 运行中人为移动传感器。

异常实验不阻塞 WG-EXP-001。
