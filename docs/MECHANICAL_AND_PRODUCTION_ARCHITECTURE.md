# WashGuard 机械结构与正式版硬件路线

> 本文记录从第一版原型机到正式产品的机械与 PCB 演进原则，避免原型阶段的临时连接方式反过来限制最终产品设计。

## 1. 第一版原型：EVAL-ADXL355Z 独立传感器模块

第一版继续使用 EVAL-ADXL355Z，不直接把它和主控板叠在一起。

推荐结构：

~~~text
洗衣机机身
    │
薄双面胶
    │
3D 打印刚性绝缘底座
    │
四点螺丝固定
    │
EVAL-ADXL355Z
    │
P1/P2 排针朝上
    │
短杜邦线
    │
面包板 + XIAO ESP32S3
    │
USB
    │
电脑
~~~

### 底座目标

底座只承担：

- 电气绝缘；
- 刚性固定；
- 保护 PCB 背面焊点；
- 提供稳定、可重复的安装姿态。

底座不应该成为软减振件。

### 材料建议

首版可优先：

- PLA：刚性较高，打印容易，适合快速实验；
- PETG：更耐用，但略有弹性；
- 不建议 TPU 等柔性材料。

### 结构建议

- 板子四个安装孔全部使用；
- 使用四个短支撑柱；
- 板底只留必要绝缘间隙；
- 不增加很高的支撑柱；
- 不在 ADXL355 下方加入软胶垫；
- 底座底面保持平整；
- 双面胶尽量薄而硬；
- 杜邦线出口做简单应力释放，避免线缆直接拉扯传感器板。

螺丝规格以实际 EVAL 板孔径测量为准，不凭经验强行使用某个尺寸。

## 2. 原型阶段为什么允许排针朝上

EVAL-ADXL355Z 的 P1/P2 本来就是为了实验和系统连接而设计的接口。官方资料明确说明，该评估板可以通过这些 vias/headers 接入原型板或现有 PCB 系统，并提供四个安装孔用于机械固定。

因此原型阶段：

- P1/P2 公排针朝上；
- 杜邦线从上方接入；
- 方便插拔、测量和排错；

是合理的。

但这只是实验接口，不是正式产品接口标准。

## 3. 正式产品不长期使用 EVAL-ADXL355Z

EVAL-ADXL355Z 是评估板，不应成为量产 WashGuard 的永久组成部分。

正式产品应把 EVAL-ADXL355Z 替换为我们自己的 Sensor PCB：

~~~text
WashGuard Sensor PCB
    │
ADXL355 芯片
    │
必要的去耦、电源与接口电路
~~~

ADXL355 本身是 LGA 表贴器件，正式 PCB 上使用官方推荐 footprint，通过锡膏 + 回流焊完成焊接，而不是靠公排针把芯片连接到 PCB。

因此正式版里不会存在“ADXL355 排针应该朝上还是朝下”这个问题。

## 4. 正式版有两种机械架构

### 方案 A：单 PCB 一体化

~~~text
洗衣机
   │
外壳刚性底面
   │
一块 WashGuard PCB
├── ADXL355
├── ESP32-S3
├── 电源
├── RGB / 蜂鸣器
└── 其他器件
~~~

优点：

- PCB 数量少；
- 连接器少；
- BOM 低；
- 装配简单；
- 体积容易做小。

风险：

- 主控、电池、蜂鸣器等质量和机械结构可能影响传感器局部振动；
- PCB 尺寸变大后，板自身弯曲/共振可能更明显；
- ADXL355 的安装位置需要谨慎设计。

是否采用该方案，需要用后续真实振动实验验证。

### 方案 B：传感器 PCB + 主控 PCB 分离

~~~text
洗衣机机身
    │
刚性安装面
    │
小型 Sensor PCB
└── ADXL355
       │
       │ 短 FFC / 锁扣连接器 / 线束
       ▼
Main PCB
├── ESP32-S3
├── 电源
├── 无线
├── RGB / 蜂鸣器
└── 其他功能
~~~

优点：

- ADXL355 传感器板可以保持很小、很硬、很轻；
- 主控和电源的质量不直接压在传感器 PCB 上；
- 更容易保持测振一致性；
- 后续更换主控方案不会改变传感器机械结构。

代价：

- 多一块 PCB；
- 多一个连接器；
- BOM 与装配复杂度略高。

对于以振动测量为核心的 WashGuard，这个方案值得优先保留。

## 5. 当前推荐的产品路线

### V0.1 原型

~~~text
EVAL-ADXL355Z
+
3D 打印刚性绝缘底座
+
四点螺丝
+
P1/P2 排针朝上
+
杜邦线
+
XIAO 面包板
~~~

目标：拿到可信振动数据。

### V0.2 工程验证

继续保留 EVAL-ADXL355Z，但逐步缩短连接线并验证：

- 位置；
- 固定刚性；
- 线缆影响；
- 安装重复性。

必要时可以设计一块简单 XIAO 主控载板，但不要改变传感器安装方式。

### V0.5 自研传感器板

设计第一块 WashGuard Sensor PCB：

- ADXL355 直接回流焊；
- PCB 尽量小而硬；
- ADXL355 靠近主要机械安装区域；
- 保留 DRDY + SPI；
- 使用低矮、锁止可靠的线束/FFC 接口，而不是杜邦线；
- 机械安装结构尽量继承原型实验中验证过的底座几何。

### V1.0 正式产品

根据 V0.5 的实验结果决定：

- 单 PCB 集成；
- 或 Sensor PCB + Main PCB 双板架构。

决定依据是实测振动一致性、装配成本、尺寸和可靠性，而不是为了省一块 PCB 提前牺牲测量质量。

## 6. PCB 与 ADXL355 正式如何连接

正式版不是：

~~~text
PCB
  ↓
排针
  ↓
EVAL-ADXL355Z
~~~

而是：

~~~text
WashGuard Sensor PCB 铜焊盘
        │
      锡膏
        │
      回流焊
        │
     ADXL355 LGA
~~~

ADI 数据手册给出了 ADXL355 的官方 PCB footprint。正式画板时必须直接采用官方推荐 land pattern，并按 LGA 工艺进行钢网、锡膏和回流焊设计。

这部分属于后面的 PCB 设计阶段，不要求原型阶段手工焊 ADXL355 芯片。

## 7. 当前 3D 打印底座应为未来留什么

即使只是 V0.1，也建议现在就保持这些工程习惯：

1. ADXL355 板固定方向明确；
2. 底座上标记 X/Y 方向；
3. 四孔固定而不是单点粘贴；
4. 传感器板和洗衣机之间保持刚性耦合；
5. 线缆从固定方向引出；
6. 线缆有应力释放；
7. 底座尺寸和安装照片记录进实验元信息；
8. 后续 Sensor PCB 尽量复用这套安装基准。

这样我们现在采的数据，未来更容易与自研 PCB 做 A/B 对照。
