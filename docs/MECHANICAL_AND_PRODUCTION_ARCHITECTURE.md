# WashGuard 机械结构与正式版硬件路线

> 本文记录从第一版原型机到正式产品的机械与 PCB 演进原则，避免原型阶段的临时连接方式反过来限制最终产品设计。

## 1. 第一版原型：EVAL-ADXL355Z 独立传感器模块

第一版继续使用 EVAL-ADXL355Z，不直接把它和主控板叠在一起。

推荐结构：

~~~text
洗衣机机身
    │
薄双面胶
    │
3D 打印刚性绝缘底座
    │
四点螺丝固定
    │
EVAL-ADXL355Z
    │
P1/P2 排针朝上
    │
短杜邦线
    │
面包板 + XIAO ESP32S3
    │
USB
    │
电脑
~~~

### 底座目标

底座只承担：

- 电气绝缘；
- 刚性固定；
- 保护 PCB 背面焊点；
- 提供稳定、可重复的安装姿态。

底座不应该成为软减振件。

### 材料建议

首版可优先：

- PLA：刚性较高，打印容易，适合快速实验；
- PETG：更耐用，但略有弹性；
- 不建议 TPU 等柔性材料。

### 结构建议

- 板子四个安装孔全部使用；
- 使用四个短支撑柱；
- 板底只留必要绝缘间隙；
- 不增加很高的支撑柱；
- 不在 ADXL355 下方加入软胶垫；
- 底座底面保持平整；
- 双面胶尽量薄而硬；
- 杜邦线出口做简单应力释放，避免线缆直接拉扯传感器板。

螺丝规格以实际 EVAL 板孔径测量为准，不凭经验强行使用某个尺寸。

## 2. 原型阶段为什么允许排针朝上

EVAL-ADXL355Z 的 P1/P2 本来就是为了实验和系统连接而设计的接口。官方资料明确说明，该评估板可以通过这些 vias/headers 接入原型板或现有 PCB 系统，并提供四个安装孔用于机械固定。

因此原型阶段：

- P1/P2 公排针朝上；
- 杜邦线从上方接入；
- 方便插拔、测量和排错；

是合理的。

但这只是实验接口，不是正式产品接口标准。

## 3. 产品化方向更新：EVAL-ADXL355Z 直接作为 Sensor PCB

2026-09-27 更新：WashGuard 当前产品化路线不再要求自研 ADXL355 传感器板，而是允许 **EVAL-ADXL355Z 直接作为正式 Sensor PCB**。

这意味着正式产品采用明确的双板架构：

~~~text
洗衣机机身
    │
刚性安装底面
    │
EVAL-ADXL355Z
（正式 Sensor PCB）
    │
短而可靠的线束 / FFC / 锁扣连接器
    │
WashGuard Main PCB
├── ESP32-S3
├── 电源
├── USB-C
├── 无线
├── RGB / 蜂鸣器
└── 其他产品功能
~~~

EVAL 板的价值是：

- 已经完成 ADXL355 周边电路；
- PCB 很小、很硬，适合作为独立振动传感器板；
- 四个安装孔非常适合机械固定；
- 原型数据与正式产品可以使用同一块传感器板，减少硬件变量；
- 不需要在比赛阶段承担 LGA 焊接、钢网、回流和传感器 PCB 验证风险。

代价是：

- 单板成本高于自研量产 Sensor PCB；
- P1/P2 原始 2×3 排针接口并不适合最终产品长期振动环境；
- 需要围绕评估板尺寸和接口设计外壳及 Main PCB；
- 如果未来进入较大批量量产，应重新评估 BOM、供应和认证成本。

因此，这条路线优先服务于比赛版、小批量工程版和早期产品化。

## 4. 推荐最终形态：单外壳、双 PCB、侧向并排

推荐 V1.0 做成一个低矮的“传感器盒 / Sensor Pod”，但内部仍然保持 Sensor PCB 和 Main PCB 分离。

推荐顶视布局：

~~~text
┌────────────────────────────────────┐
│                                    │
│  EVAL-ADXL355Z      WashGuard      │
│  20.32 × 20.32      Main PCB       │
│                                    │
│  [Sensor 区]         [主控区]       │
│                                    │
└────────────────────────────────────┘
~~~

不建议把 Main PCB 直接叠在 EVAL-ADXL355Z 正上方。优先侧向并排：

- Sensor PCB 直接固定在外壳底壳的刚性 Sensor Island；
- Main PCB 使用另一组安装柱；
- 两块板通过短柔性连接连接；
- 主控板、电源、蜂鸣器等质量不直接压在传感器板上。

建议第一版成品外壳目标范围：

- 长：约 55～65 mm
- 宽：约 35～45 mm
- 高：约 14～20 mm

最终尺寸由 Main PCB 和连接器实际布局决定。

## 5. 推荐剖面结构

~~~text
       顶盖
┌──────────────────────────────┐
│ RGB / Button / Status        │
│                              │
│     Main PCB                 │
│     ESP32-S3                 │
│                              │
│  短柔性线束                  │
│       │                      │
│ EVAL-ADXL355Z                │
│ 四点螺丝刚性固定             │
├──────────────────────────────┤
│ 刚性底壳 / Sensor Island     │
├──────────────────────────────┤
│ 薄双面胶 / 磁吸安装层        │
└──────────────────────────────┘
          洗衣机
~~~

关键要求：

1. EVAL-ADXL355Z 必须直接、刚性地固定到底壳；
2. 不在 Sensor PCB 与底壳之间加入泡棉或软胶垫；
3. Main PCB 与 Sensor PCB 分开安装；
4. 线束需要应力释放；
5. 外壳底面尽量平整；
6. Sensor 区域机械结构应比外壳其他区域更硬。

## 6. 正式接口：不要继续使用直立杜邦排针

V0.1 原型可继续使用 P1/P2 直立公排针 + 杜邦线。

正式产品建议保留 EVAL-ADXL355Z 本体，但改变接口方式。优先级：

### 方案 A：拆除 P1/P2 直立排针，直接焊柔性线束

~~~text
EVAL P1/P2 焊孔
      │
8 芯短柔性线束
      │
JST-GH / Molex / 其他锁扣连接器
      │
Main PCB
~~~

优点：

- 高度最低；
- 抗振比杜邦线可靠；
- 结构简单；
- 适合比赛版和小批量。

### 方案 B：P1/P2 焊低矮直角连接器

优点：

- 可拆卸；
- 维修方便；
- 线束方向可以水平出线。

需要确认连接器与 EVAL 板孔距、外壳高度和机械干涉。

### 方案 C：设计一块很小的接口转接板

转接板只负责：

- 对接 P1/P2；
- 汇总成一个低矮锁扣连接器；
- 提供应力释放。

不改变 EVAL-ADXL355Z 作为 Sensor PCB 的定位。

当前优先建议 **方案 A 或 C**。

正式版不建议继续使用松动风险较高的 Dupont 杜邦插头。

## 7. Main PCB 的职责

既然 EVAL-ADXL355Z 固定作为 Sensor PCB，Main PCB 可以集中承担：

- ESP32-S3；
- USB-C；
- 5V 输入与 3.3V 电源；
- Wi-Fi / BLE；
- RGB LED；
- 蜂鸣器；
- 按键；
- 可选电池与充电管理；
- 可选本地存储；
- Sensor 接口。

比赛版和 V1.0 推荐先使用 USB-C 供电，不急于加入电池。

## 7. 当前 3D 打印底座应为未来留什么

即使只是 V0.1，也建议现在就保持这些工程习惯：

1. ADXL355 板固定方向明确；
2. 底座上标记 X/Y 方向；
3. 四孔固定而不是单点粘贴；
4. 传感器板和洗衣机之间保持刚性耦合；
5. 线缆从固定方向引出；
6. 线缆有应力释放；
7. 底座尺寸和安装照片记录进实验元信息；
8. 后续 Sensor PCB 尽量复用这套安装基准。

这样我们现在采的数据，未来更容易与自研 PCB 做 A/B 对照。


## 8. V0.1 线缆应力释放结构

V0.1 不采用纯 3D 打印弹性卡扣作为线缆固定方式。

推荐结构：

~~~text
可拆压线片
   │
M2 螺丝 ×2
   │
杜邦线束
   │
U 型浅槽
   │
3D 打印底座
~~~

设计原则：

- U 型浅槽与底座一体打印；
- 使用独立压线片轻压线束；
- 压线片使用 2 颗 M2 螺丝固定；
- 底座侧可采用热熔铜螺母或预留六角螺母槽；
- 只做应力释放，不把杜邦线夹死；
- 线束应保留小弯曲余量，避免把拉力直接传到 EVAL-ADXL355Z 的 P1/P2 排针；
- 首版优先可靠性和可重复装配，不优先追求免工具卡扣。

后续正式产品若改为 FFC、锁扣连接器或定制线束，可以重新设计更紧凑的卡扣式应力释放结构。
